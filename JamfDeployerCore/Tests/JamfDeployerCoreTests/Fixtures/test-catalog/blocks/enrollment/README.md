# Enrollment

A computer PreStage for Automated Device Enrollment: devices become
supervised, MDM cannot be removed, Activation Lock is prevented, and the
consumer Setup Assistant panes (Apple ID, Siri, Screen Time, payments…) are
skipped.

Requires an Apple Business Manager / Apple School Manager connection (ADE
instance) in Jamf Pro — set it up in the tenant's Day 0 steps first.
