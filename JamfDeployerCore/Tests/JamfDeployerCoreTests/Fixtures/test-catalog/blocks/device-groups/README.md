# Device Groups

Creates the groups other blocks scope to:

- Pilot (static) — add test Macs by hand; the safe first scope for production tenants
- All Managed Macs, Laptops, Desktops, Apple Silicon Macs (smart)

Each group works for both Jamf Pro scoping (policies, profiles, App
Installers) and Platform scoping (Blueprints, compliance benchmarks). App
Installers only accept smart groups; pick one of the smart groups for App
Catalog apps.
