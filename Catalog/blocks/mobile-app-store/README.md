# iPad and iPhone Apps

Deploys App Store apps to iPads and iPhones as managed apps, with
device-based Apps and Books licenses.

The picker lists only apps the tenant holds licenses for. Every tenant the
block deploys to needs licenses for the same apps in its own Apps and Books
location — free apps too, obtained in Apple Business Manager.

The **Apps and Books location** setting names the location to license from.
The picker fills it in; on each tenant the location is looked up by that
name. The block is scoped to a mobile device group.
