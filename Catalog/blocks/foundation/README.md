# Foundation

The base layer every baseline starts with. Creates the shared categories,
device groups and extension attributes that other building blocks scope to
and organize under.

Always on: other blocks reference its groups, so it cannot be removed while
any other block is selected.

## Objects created
- Categories: Security, Applications, Maintenance, Enrollment
- Device groups: Pilot (static), All Managed Macs, Laptops, Desktops,
  Apple Silicon Macs (smart)
- Extension attributes: Baseline Marker (text), Deployment Ring (pop-up)
